# x402 spot-buy sample

Written weekly by `.github/workflows/spot-buy.yml` on `master` (see `lib/spot-buy.js`): a small random
sample of endpoints the x402 Trust Index calls "go" is bought with a dedicated wallet, and each result says
what happened after paying. `latest.json` is the newest run, `results/<date>.json` every run.
See https://x402-doctor.fizzl.eu/trust
