# Fizzl's DeWEB site on X Layer

Written by `.github/workflows/deweb-xlayer.yml` on `master`. `deweb-state.json`: the TapeOut processor,
circuit, container and on-chain name of the site, and when it was last written. `index.html`: the page as
last published; browsers read it from X Layer's SiteRegistry and check it against its SHA-256.
