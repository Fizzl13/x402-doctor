# x402 health, week ending 2026-10-12

Every resource in the CDP Bazaar and the MPP directory, checked daily the way a paying agent would (the 402 challenge only, never paid). Window: 2026-10-06 to 2026-10-12 (7 days).

## The numbers

- **34,344** resources on **2,385** hosts were checked on 2026-10-12.
- **93.8%** were clean: an agent could pay them without a second thought.
- **2.9%** (996) answered with a caution: testnet only, an unknown token, a URL mismatch and the like.
- **3.3%** (1,135) could not be paid at all. Payable, cautions included: 96.7% (2026-10-06: 97.8%).
- This week: **308** stopped being payable, **635** were fixed, **4,029** went back and forth, **727** were new.
- Median price of a payable call: **$0.01**.
- By protocol: x402 33,995 (94.2% clean, 96.8% payable), MPP 349 (56.2% clean, 88.3% payable). MPP endpoints come from the MPP directory (Stripe + Tempo).
- Not counted: **586** MPP endpoints that check their input before asking for payment (for example "symbol is required"); without example input they can't be judged.
- Left out: **130** test, staging or tunnel endpoints on 55 hosts (addresses such as staging., sandbox., testnet, ngrok or Vercel previews).

## Why payments would fail or need care

| Reason | Resources | What to fix |
|---|---:|---|
| Don't answer 402 at all, so there is nothing to pay | 1,107 | make the listed route answer 402 (a moved or renamed endpoint stays listed under its old URL until a payment goes through the new one) |
| Name another URL in their 402 than the one requested | 711 | build resource.url from your public origin (behind a TLS proxy: trust proxy, so it stays https) |
| Offer only testnet payment options | 169 | add a mainnet option (for example Base, eip155:8453) or delist the test endpoint |
| Name another host as the MPP realm than the one they're served on | 102 | set realm to the public host name of the endpoint |
| Answer 402 without a valid x402 challenge | 23 | send the PaymentRequired object (base64 JSON in the PAYMENT-REQUIRED header, mirrored in the body) |
| Send an MPP challenge without an expiry | 10 | set expires on each challenge (a few minutes ahead), so a captured challenge cannot be replayed later |
